Scheduled Payments

Planning future payments inside a mobile banking app. A UX/UI concept focused on reducing cognitive load and making financial planning more predictable.

Role UX/UI Designer
Platform Desktop
Type Test Assignment
Tools Figma
Смотреть в Figma ← Все проекты

Overview

The goal of this project was to redesign the experience of scheduled payments within a mobile banking application. The solution focused on helping users understand upcoming transactions, manage recurring payments and reduce uncertainty before money is withdrawn.

Challenge

The Problem

Users often forget about future payments. The existing flow provided limited visibility into upcoming transactions, making it difficult to plan expenses and avoid mistakes.

Goals

Increase visibility

Show upcoming payments clearly.

Reduce mistakes

Help users understand what will happen before confirmation.

Improve planning

Support financial planning through better interaction.
